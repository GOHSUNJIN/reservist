Introduction
ReservistGO

What is ReservistGO?

ReservistGO is a mobile-first attendance management system for SPF G Division reservists. It handles the full cycle of a reporting period, covering everything from enrolling new members to tracking daily check-ins, managing leave, and generating reports for payroll and welfare.

ℹ️

As an Admin, you manage your department's roster, approve requests, correct attendance records, and export reports. You do not need database access for day-to-day operations. Everything is done through the app.

System Roles
👤
Reservist
Self-service only. Can check in, submit leave requests, view their own attendance, and manage their profile. Cannot see other members' details.
🛡️
Admin (Supervisor)
Manages the roster, approves signups and leave, corrects attendance, adds/removes personnel, and exports reports, within their department only.
⭐
Master (Superadmin)
All Admin capabilities, plus: switch between departments, create/remove Admin accounts, and promote reservists to Admin.
The Four Tabs

Your admin interface has four tabs at the bottom of the screen. Each covers a distinct part of managing your team.

📊

Overview

Daily attendance dashboard. See at a glance how many are Present, on MC, Absent, or Pending. Pending signups and leave requests also appear here for quick action.

📋

Roster

Live attendance board. See every reservist's current status as they check in. Mark statuses, correct times, add welfare notes, and view check-in phases in real time.

🕐

Log

Full time records for each person. Edit all four check-in phases, flag missing clock-outs, generate a WhatsApp attendance summary, and export to Excel or PDF.

👥

People

Three sub-tabs: Requests (approve signups and leave), Roster (add/remove personnel, view history), and Team (manage supervisor accounts).

Key Concepts
Cycle

A reporting period, typically 2 weeks (Tue to Mon). Each cycle has a start date, end date, and a dekit date. Only one cycle is Live at any time. The app auto-creates upcoming cycles 8 cycles ahead.

Reporting Days

Weekdays within a cycle when reservists are expected to report. Weekends are auto no-report. Admins can toggle additional no-report days (public holidays, stand-downs).

Departments

Ops Security uses a 4-phase check-in. CAS (Crime Alert) uses a 2-phase check-in. Data is fully scoped per department. Master accounts can switch between them.

Attendance Statuses
Present MC Absent Pending

Pending means no status yet (awaiting check-in or admin action). Absent is auto-set at midnight for anyone still Pending.

Check-in Phases

Ops Security reservists check in across four phases throughout the day. Each phase is time-stamped and GPS-verified where applicable.

Phase 1
Check In
09:00 to 12:00
Phase 2
Lunch Out
12:00 to 14:00
Phase 3
Return
14:00 to 18:00
Phase 4
End of Shift
After 18:00
⚠️

CAS department uses only Phase 1 (Check In) and Phase 4 (End of Shift), with no lunch phases. GPS verification applies to Phases 1 and 3. A missing Phase 4 time triggers a "No clock-out" flag in the Log tab.

Roster Tab:What You See

Each Roster Card Shows

  • Name & contact:tap contact to copy
  • Status badge:colour-coded (green/amber/red/gray)
  • Check-in phases:IN / LCH / BACK / OUT times
  • GPS distance:metres from HQ at check-in
  • Attendance rate:flagged amber if below 75%
  • Welfare note:if one has been added

Actions You Can Take

  • Mark Present / MC / Absent individually
  • Mark All Absent:end-of-day closure (with confirm)
  • Mark All Present:bulk approval (with confirm)
  • Edit phase times:correct any timestamp manually
  • Add welfare note:visible to the reservist
  • Filter by status:All / Present / MC / Absent / Pending
  • Search by name:persistent across navigation
Log Tab:Time Records & Reporting

What You Can Do

  • Edit all 4 phases for any person on any date
  • Add welfare / daily notes per person
  • See Late flag:check-ins >1hr after start time
  • See No Clock-out flag:missing Phase 4 time
  • View edit history:who changed what and when
  • Filter & search:by status, name, or date

Reporting & Export

  • Excel export:full cycle matrix with colour-coded statuses and meal column
  • Print / PDF:A4 formatted report including meal claims summary
  • WhatsApp summary:auto-generated text with names; edit before sending
  • Per-person history export:from the history modal in People > Roster
ℹ️

The Log tab badge (orange dot on the nav icon) lights up when there are attendance records awaiting review. For example, pending check-ins that need a status decision before end of day.

GPS & Late Flags
GPS Verified

Check-in within 250m of HQ. Distance is recorded permanently. If GPS fails after 5 attempts, a bypass is offered and flagged in the log.

Late Badge

Shown when Phase 1 is more than 1 hour after shift start. Reservist is prompted to provide a written reason, which you can see in the Log.

No Clock-out

Marked Present but Phase 4 is missing. Must be manually entered before payroll. Also affects meal allowance eligibility.

People Tab & Key Workflows
ReservistGO

People Tab

The People tab has three sub-tabs. A red dot on the People nav icon means there are pending signups or leave requests awaiting your action.

Requests
  • Pending Signups:New and Returning enrollments waiting for approval
  • Pending Leave Requests:MC, Personal Leave, and Other leave types
  • Approve or decline individually; bulk-select for batch actions
  • Rejection requires a written reason (shown to the reservist)
  • Search and filter by type within each section
Roster
  • Add Personnel:single or bulk add with a pasted list
  • Re-enroll:reactivate a previously removed member
  • View history:full attendance across all cycles
  • Reset password:set a temporary password without DB access
  • Remove:deactivate and remove from current cycle
Team (Admin only)
  • View all active supervisors in your department
  • Add Supervisor:create new admin account (Master only)
  • Remove Supervisor:demote back to reservist (Master only)
  • Promote Reservist:elevate existing member to admin (Master only)
Workflow 1:Approving a New Signup
Self-signup (Reservist-initiated) Most common
  1. Reservist opens the app and taps Sign up
  2. They enter name, phone number, password, and select department
  3. You see their request in People > Requests > Pending Signups with a New badge
  4. Tap Approve. They immediately appear in the Roster and can log in
Returning reservist Re-enrollment
  1. Reservist logs in with their existing number and password
  2. System detects their deactivated account and auto-submits a re-enrollment
  3. You see their request with a Returning badge
  4. Tap Approve. Their account is reactivated and they join the current cycle
Workflow 2:Handling a Leave Request
Approving leave
  1. Reservist submits a leave request (MC, Personal, or Other) from their app
  2. Go to People > Requests > Pending Leave Requests
  3. Review: name, date, type, and any reason provided
  4. Tap Approve. Attendance is updated automatically for that date
✅

Approved MC marks the reservist's status as On MC. They cannot check in for that date.

Declining leave
  1. Tap Decline on the request
  2. Enter a written reason. This is mandatory and will be shown to the reservist
  3. Confirm. The request is marked Declined in their history
  4. They may resubmit a new request if needed
⚠️

For bulk decline, the same reason applies to all selected requests. Make sure it's appropriate for everyone selected.

Workflow 3:Adding Personnel Directly
Single add
  1. Go to People > Roster, tap Add Personnel
  2. Enter name and phone number
  3. If the person was previously removed, search for them first. Reusing their account avoids duplicates
  4. Confirm. They appear in the roster immediately
Bulk add Efficient for large groups
  1. Tap the Bulk button in People > Roster
  2. Paste a list of names and phone numbers (one per line)
  3. Review the parsed preview
  4. Enter a default password (min. 6 characters) for all accounts
  5. Confirm. All are added at once

Cycles, Meal Allowance & Glossary
ReservistGO

Managing Cycles

Cycles are your primary reporting container. The app auto-creates upcoming cycles, but you control their settings.

Cycle Settings

  • Label:editable inline (e.g. "Cycle 18/2026")
  • Start / End / Dekit dates:set the reporting window
  • Live toggle:marks this cycle as the active one
  • Meal allowance:on/off toggle per cycle
  • Cycle notice:broadcasts a message to all reservists in check-in view
  • No-report days:toggle individual days or paste a bulk list

No-Report Days

  • Weekends are automatically excluded
  • Toggle any weekday as no-report (public holidays, stand-downs)
  • No-report days show as amber on the reservist's calendar
  • Reservists do not need to check in on no-report days
  • Bulk add by pasting a list of dates
⚠️

The dekit date is automatically a no-report day. Reservists attend only to return equipment.

Meal Allowance
  • Enable/disable per cycle via the toggle in cycle settings
  • Reservist must complete Phase 1 (check-in) and Phase 4 (end of shift)
  • Minimum 6 hours of work time required for eligibility
  • A work timer is shown on the reservist's check-in screen when meal is active
  • Meal eligibility appears as a Meal column in the Excel export
  • The printed PDF report includes a Meal Claims summary
  • Missing Phase 4 (no clock-out) makes a reservist ineligible for that day
  • Admin can manually enter a missing Phase 4 time in the Log tab

Tips & Quick Reference
ReservistGO

Tips for New Admins

These habits will help you stay on top of daily operations from the start.

🔴 Check the red dots daily

Red dots on the People and Log nav icons mean something needs your attention: pending signups, leave requests, or unreviewed attendance. Clear these before end of day.

⏰ Run Mark All Absent before midnight

Anyone still Pending at midnight is auto-marked Absent. Use Mark All Absent in the Roster tab at end of day to do this intentionally and close out the day cleanly.

📋 Fix No Clock-out flags before export

Missing Phase 4 times affect meal allowance calculations. Always review the Log tab for "No clock-out" flags before generating your Excel export for payroll.

📝 Use welfare notes proactively

If someone has a known reason for absence (medical, family), log a welfare note. It appears in their check-in view, making it visible to them and useful as a record for you.

🔁 Re-enroll, don't re-add

When adding a returning reservist, search for their name or number first. Selecting an existing inactive account reactivates it cleanly without creating a duplicate.

✉️ Decline with clear reasons

Rejection reasons are shown directly to the reservist. Write them as if you're addressing the person: clear, professional, and actionable (e.g. "Please resubmit with supporting MC document").

📊 Export at end of cycle

The Excel export contains the full attendance matrix with meal eligibility colour-coded. Export this at the end of every cycle and keep a copy for your records.

🔐 Reset passwords without IT

If a reservist is locked out, go to People > Roster, find their card, and use Reset Password. Give them a temporary password and ask them to change it after logging in.

Daily Admin Checklist
Morning
  • Check People tab for overnight signups or leave requests
  • Approve or action pending requests before parade
  • Monitor Roster tab as reservists begin checking in
  • Note any "Late" flags and follow up if needed
End of Day
  • Run Mark All Absent for anyone still Pending
  • Review Log tab for "No clock-out" flags and fill in Phase 4 times
  • Send WhatsApp attendance summary if required
  • Add welfare notes for any known absences or concerns
